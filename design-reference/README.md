# Design Reference Assets

This directory is reserved for owner-supplied visual references.

Expected files:

- `latest-stitch-export.zip`: latest Stitch export for visual reference only.
- `logo.png`: Rahal crown/shield/R logo.
- `storefront.png`: storefront/sign image used to confirm branch address and contact details.

Do not copy Stitch HTML, CDN scripts, demo JavaScript, temporary external images, or inconsistent demo data into production code. Use screenshots and `DESIGN.md` inside the export only as design direction.
