# RAHAL web fonts

This directory contains the variable WOFF2 subsets used by the public experience:

- Manrope for Latin interface text.
- Cormorant Garamond for Latin display headings.
- IBM Plex Sans Arabic for Arabic interface text and headings, using explicit 400–700 weights so browsers never synthesize the oversized heavy forms used previously.

The files are self-hosted so production builds and customer pages do not depend on a third-party font request. These typefaces are distributed by their authors under the SIL Open Font License 1.1 and were obtained through the Google Fonts delivery used by Next.js.
